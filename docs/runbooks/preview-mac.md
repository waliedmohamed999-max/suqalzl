# معاينة سوق الزل على جهاز الماك (دليل خطوة بخطوة)

> **المالك:** devops-engineer — **المهمة:** M1-04 — **آخر تحديث:** 2026-11-19
> **لمين:** صاحب المشروع (مش لازم تكون مبرمج). الدليل ده بيشغّل نسخة تجريبية من الموقع على جهازك بس.
> **مهم:** كل البيانات توضيحية. مفيش دفع حقيقي ولا رسائل SMS حقيقية ولا أي مفاتيح. مفيش حاجة بتطلع بره جهازك.

## الفكرة في سطرين

بتنزّل برنامجين مجانيين (Docker و Node) مرة واحدة، وتكتب أمر واحد في الـ Terminal، والموقع بيشتغل. بعد كده تفتحه من الكمبيوتر ومن موبايلك (لازم يكونوا على نفس الـ Wi-Fi).

---

## أولاً: التجهيز (مرة واحدة بس)

### 1. نزّل Docker Desktop

1. افتح https://www.docker.com/products/docker-desktop/
2. اختار **Download for Mac - Apple Silicon** (لو الماك Air بتاعك حديث، 2020 أو أحدث، ده الصح). لو جهازك قديم (Intel) اختار نسخة Intel.
3. افتح الملف اللي نزل واسحب أيقونة Docker لمجلد Applications.
4. افتح Docker من Applications. هيسألك على الموافقة على الشروط وكلمة سر الجهاز: وافق.
5. استنى لحد ما تظهر عبارة **Engine running** (أو الأيقونة الحوت فوق في الشريط تثبت).

### 2. نزّل Node.js (النسخة 24)

اختار طريقة واحدة بس:

**الطريقة الأسهل (المثبت الرسمي):**
1. افتح https://nodejs.org
2. نزّل النسخة رقم **24** (من صفحة Downloads، لو الافتراضي رقم تاني اختار 24 من القائمة) ثم افتح الملف وكمّل التثبيت.

**أو عن طريق nvm (لو بتفضّله):**
```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/master/install.sh | bash
```
اقفل الـ Terminal وافتح واحد جديد، وبعدين:
```bash
nvm install 24
```

### 3. نزّل الكود

افتح **Terminal** (اضغط Cmd + Space واكتب Terminal) وانسخ الأوامر دي واحد واحد:

```bash
xcode-select --install     # لو ظهرت نافذة، اضغط Install واستنى. لو قال إنه متثبت، كمّل
git clone <رابط المستودع> suqalzl
cd suqalzl
```

> رابط المستودع هتاخده من المهندس أو من صفحة المشروع على GitHub (زرار Code ثم HTTPS). لو المستودع خاص، GitHub هيطلب منك تسجيل الدخول.

## ثانياً: التشغيل (كل مرة عاوز تعاين)

1. اتأكد إن **Docker Desktop شغال** (أيقونة الحوت فوق).
2. في الـ Terminal، من جوه مجلد `suqalzl`:

```bash
bash scripts/preview.sh
```

أول مرة بتاخد **من 5 لـ 15 دقيقة** (بينزّل ويجهّز كل حاجة). المرات الجاية أسرع بكتير.

3. لما تشوف مربع مكتوب فيه **PREVIEW READY**، يبقى جاهز. هتلاقي فيه:
   - **العنوان** (مثلاً `http://192.168.1.20:3000`): ده اللي بتفتحه.
   - **بيانات دخول الإدارة** (الإيميل وكلمة السر).
   - **بيانات الموظف التوضيحي**.
4. أول فتح للصفحة بياخد دقيقة (الموقع بيجهّز نفسه). بعد كده بيبقى سريع.

### افتحه من الكمبيوتر
افتح Safari أو Chrome واكتب العنوان اللي ظهر في المربع **بالظبط** (اللي فيه أرقام زي `192.168...`). **متستخدمش** `localhost`، لأن تسجيل الدخول والحفظ مش هيشتغلوا عليه.

صفحة الإدارة: نفس العنوان وفي الآخر `/admin`.

### افتحه من الموبايل
1. اتأكد إن الموبايل على **نفس شبكة الـ Wi-Fi** بتاعة الماك (مش بيانات الموبايل).
2. افتح المتصفح في الموبايل واكتب نفس العنوان اللي في المربع.

### كود التحقق (OTP)
لما تسجّل دخول بالرقم أو تعمل حساب، الموقع بيطلب كود. الكود **بيظهر في نافذة الـ Terminal** اللي شغّلت فيها الأمر، في سطر شبه ده:

```
[sms:console] to=+9665***1 text="... 123456 ..."
```

انسخ الأرقام اللي في الرسالة واكتبها في الموقع. مفيش رسالة بتتبعت لأي حد.

### الإيميلات التجريبية
أي إيميل بيبعته الموقع بيظهر في http://localhost:8025 (على الماك بس).

## ثالثاً: الإيقاف

1. في نافذة الـ Terminal اضغط **Ctrl + C** (ده بيوقف الموقع).
2. بعدين:
```bash
bash scripts/preview-stop.sh
```
ده بيوقف قاعدة البيانات والخدمات. **البيانات بتفضل محفوظة** للمرة الجاية.

لو عاوز تمسح كل حاجة وتبدأ من الصفر:
```bash
bash scripts/preview-stop.sh --wipe
```
(هيسألك تكتب كلمة `wipe` للتأكيد.)

لتشغيل أسرع لما تكون شغلته قبل كده من غير ما تغيّر حاجة: `bash scripts/preview.sh --skip-seed`

## رابعاً: حل أشهر المشاكل

| المشكلة | الحل |
|---|---|
| **"Docker is not installed"** أو "docker: command not found" | Docker Desktop مش متثبت أو مفتحتوش ولا مرة. ارجع لخطوة 1 وافتحه من Applications، وبعدين اقفل الـ Terminal وافتح واحد جديد. |
| **"Docker is not running"** / "Cannot connect to the Docker daemon" | افتح Docker Desktop واستنى لحد "Engine running"، وكرّر الأمر. السكربت بيحاول يفتحه لوحده، بس لو اتأخر افتحه إنت. |
| **"Node.js 24 is required"** | Node مش متثبت أو نسخته قديمة. ارجع لخطوة 2. **لازم تقفل الـ Terminal وتفتح واحد جديد** بعد التثبيت. للتأكد اكتب `node -v` ولازم يظهر `v24...`. |
| **"Port 3000 is used by another program"** (المنفذ مشغول) | في برنامج تاني بياخد المنفذ. اقفل أي موقع تجريبي شغال، أو شغّل على منفذ تاني: `PREVIEW_PORT=3001 bash scripts/preview.sh` (واستخدم الرقم الجديد في العنوان). |
| **"port 5432 ... is used by another program"** | عندك PostgreSQL تاني شغال على الجهاز. اقفله (لو متثبت من Postgres.app اضغط Quit) وكرّر الأمر. |
| **الماك سأل: "Do you want the application node to accept incoming network connections?"** | اضغط **Allow** (السماح). ده اللي بيخلي الموبايل يوصل للموقع. لو ضغطت Deny بالغلط: **System Settings > Network > Firewall > Options** وفعّل السماح لـ node، أو أطفئ الجدار الناري مؤقتاً وقت المعاينة. |
| **الموبايل مش بيفتح العنوان** | (1) اتأكد إن الاتنين على نفس الـ Wi-Fi. (2) بعض شبكات الشركات والفنادق بتمنع الأجهزة من رؤية بعض: جرّب هوت سبوت من موبايل تاني أو شبكة البيت. (3) اتأكد إن الجدار الناري سمح لـ node (الصف اللي فوق). (4) لو الـ Wi-Fi اتغيّر، اقفل وشغّل `bash scripts/preview.sh` تاني عشان يجيب العنوان الجديد. |
| **تسجيل الدخول بيرجّع خطأ أو مش بيحفظ** | غالباً فاتح الموقع على `localhost`. افتحه بالعنوان اللي فيه الأرقام (اللي ظهر في المربع). |
| **الصفحة بتفضل تحمّل أول مرة** | طبيعي: الموقع بيجهّز الصفحة أول مرة (لحد دقيقة). استنى وبعدين حدّث الصفحة. |
| **الصور مش ظاهرة** | استنى دقيقة وحدّث. لو فضلت مش ظاهرة، ابعت آخر 30 سطر من الـ Terminal للمهندس. |
| **اتغيّرت كلمة سر الإدارة؟** | كلمة السر متحفوظة في ملف `.env` جوه المجلد (سطر `SUPER_ADMIN_PASSWORD`). ومتتشاركش على أي مكان. هي كمان بتتطبع في مربع PREVIEW READY كل مرة. |

## لو اتعلقت

صوّر شاشة الـ Terminal (أو انسخ آخر 30 سطر) وابعتها للمهندس. ممكن تلاقي سجل كامل في الملف `.preview/app.log`.

## للمهندسين (ملاحظات تقنية)

- `scripts/preview.sh` بيشغّل التطبيق بـ **`next dev`** مش `build + start` عن قصد: `next start` بيحط `NODE_ENV=production` فالـ cookies بتبقى `Secure` وعنوان الشبكة `http://192.168.x.x` مش `localhost`، فالمتصفح بيرفضها (الدخول والسلة بيفشلوا)، ومزود SMS الـ console بيتعطل. لو عاوزين وضع الإنتاج في المعاينة لازم الـ backend يخلي `secure` مرتبط بـ `PREVIEW_MODE` أو `APP_URL=https`.
- `APP_URL` / `AUTH_URL` / `NEXT_PUBLIC_APP_URL` بيتظبطوا تلقائياً على عنوان الـ Wi-Fi (`ipconfig getifaddr en0`)، لأن `assertSameOrigin` (src/lib/http.ts) بيقارن الـ Origin بـ `APP_URL`. لذلك لازم الفتح بنفس العنوان على الماك كمان.
- المتغيرات اللي السكربت بيصدّرها (مش بيكتبها في `.env`): `PREVIEW_MODE=true`، `SEED_DEMO=true`، `STORAGE_PROVIDER=auto`، `SMS_PROVIDER=console`، `WHATSAPP_PROVIDER=console`، `PAYMENTS_MODE=sandbox`، `APP_ENV=development`.
- كلمات السر (`SUPER_ADMIN_PASSWORD`، `SEED_DEMO_STAFF_PASSWORD`) بتتولد عشوائي في `.env` (صلاحية 600، مش داخل git) أول مرة.
- الحالة (pid، السجل، الملخص) في `.preview/` (متجاهَل في git).
- لو شغّلت الـ seed على قاعدة فيها بيانات قديمة: `bash scripts/preview-stop.sh --wipe` ثم شغّل من جديد.
